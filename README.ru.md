# RenameTime — переименование файлов по дате через контекстное меню Windows

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | **Русский**

Переименование файлов и папок в формат «дата + исходное имя» одним щелчком правой кнопки:

```
отчёт.pdf (создан 2015-10-10)  →  20151010 отчёт.pdf
```

Выберите один или несколько файлов/папок в проводнике, нажмите правую кнопку →
**Добавить префикс даты**. Файлы и папки можно выбирать вперемешку, а множественное
выделение обрабатывается одной партией.

## Скачать

Загрузите из раздела **[Releases](../../releases)**
(Windows 10/11, Python не требуется). После загрузки запустите программу один раз
и нажмите «Зарегистрировать в контекстном меню».

| Сборка | Файл | Размер | Скорость (1 файл) | Примечания |
|---|---|---|---|---|
| **Рекомендуется** | `RenameTime-fast.zip` | 15 МБ | **~1,6 с** | Распаковывается в папку с `RenameTime.exe` и каталогом `_internal`. **Переносите всю папку целиком** — один exe работать не будет |
| Портативная | `RenameTime.exe` | 15 МБ | ~2 с | Один файл, работает откуда угодно, но при каждом запуске распаковывает себя |

> С версии 1.2 рекомендуется zip-сборка: однофайловый exe при каждом старте распаковывает
> зависимости во временный каталог, добавляя примерно 1,5 с. Папочная сборка загружается
> напрямую и стартует заметно быстрее. Функционально они идентичны.

## Что нового в v1.2 — с 16,8 с до 1,6 с

**Само переименование всегда занимало около 1 миллисекунды.** `os.rename` меняет только
запись каталога — он не читает и не записывает содержимое файла, поэтому даже файл
в 300 МБ переименовывается за 0,8 мс. Всё время уходило на запуск программы.

| Этап | Время |
|---|---|
| Само переименование | **1 мс** |
| Распаковка exe при запуске (каждый раз) | ~1500 мс |
| Ожидание сбора партии (ошибка в логике) | ~15000 мс |

Три исправления:

1. **Ожидание сбора партии простаивало все 15 секунд** (главная причина). Старая логика
   считала партию завершённой, как только очередь молчала 1 секунду. Но однофайловый
   exe на PyInstaller распаковывается около 1,5 с, поэтому процессы стартуют неравномерно:
   к моменту, когда первый процесс записал путь и вышел, остальные ещё даже не были
   созданы. Это выглядело как «партия закончена», и ожидание доходило до предела в 15 с.
   Теперь партия завершается только когда выполнены **оба** условия: «очередь молчит
   0,35 с» **и** «других процессов, которые ещё запускаются, нет».
2. **Переход на сборку onedir** (необязательный zip). onefile при каждом запуске
   распаковывает весь runtime во временный каталог (~1,5 с); onedir загружается напрямую
   (~350 мс).
3. **Исправлены три гонки, из-за которых файлы могли остаться непереименованными**
   (иногда при выборе нескольких файлов часть не меняла имя):
   - получение очереди изменено с «прочитать и удалить» на **атомарное переименование**,
     чтобы путь, пришедший в момент удаления, не исчезал вместе с файлом очереди;
   - ведущий процесс **удерживает пакетный блокировку до самого конца**. Если освободить
     её раньше, опоздавший процесс станет «ведомым» и выйдет, а его путь навсегда
     останется в очереди необработанным;
   - PID, записываемый в файл блокировки, никогда не читался. Если ведущий процесс
     принудительно завершали, блокировка висела 30 секунд, и всё это время каждый процесс
     только записывал путь, а никто не выполнял. Теперь проверяется, жив ли владелец, и
     блокировка сразу перехватывается.

Измерено от щелчка правой кнопкой до переименования (12 замеров, **ни одного пропуска**):

| Выбрано файлов | v1.0 | v1.2 |
|---|---|---|
| 1 | 16,8 с | **1,6 с** |
| 5 | 16,9 с | **1,6 с** |
| 20 | 17,4 с | **2,5 с** |
| 50 | 17,5 с | **4,9 с** |

## ⚠️ Известные проблемы

### HTML-файлы: контекстное меню работает неверно, пока непригодны

При использовании контекстного меню на файле `.html` браузер может показать запрос
безопасности «Вы хотите открыть этот файл?». **Файл не переименовывается, HTML-файлы
сейчас непригодны для использования.**

| Пункт | Подробности |
|---|---|
| Симптом | Вместо переименования открывается диалог браузера |
| Область | `.html` (возможно, `.htm`); прочие типы файлов и папки работают нормально |
| Текущее состояние | В автоматических тестах проекта HTML-файлы (в том числе с меткой«загружено из Интернета», `Zone.Identifier`) переименовываются корректно; однако в реальном проводнике проблема воспроизводится, поэтому **первопричина не установлена и считается нерешённой ошибкой** |
| Обходные пути | ① Включите «Показывать окно результатов», чтобы хотя бы видеть, вызывается ли программа; ② Отключите «Выполнять сразу» и используйте режим предварительного просмотра; ③ Перетащите HTML-файл на значок `RenameTime.exe` |

При воспроизведении приложите `%APPDATA%\RenameTime\launch.log` — программа записывает
полученные аргументы при каждом запуске.

## 1. Установка (30 секунд)

1. Дважды щёлкните `RenameTime.exe`;
2. Откройте вкладку **«Контекстное меню»** и нажмите **«Зарегистрировать в контекстном меню»**;
3. Готово. Теперь пункт появляется при щелчке правой кнопкой по файлу или папке.

> Регистрация выполняется в реестре текущего пользователя (`HKCU\Software\Classes`) —
> **права администратора не требуются**. Для удаления нажмите «Убрать из контекстного меню»,
> затем удалите файлы программы.

## 2. Настройки

### Основные

| Параметр | Описание |
|---|---|
| Язык интерфейса | Русский / 简体中文 / English / 日本語 — весь интерфейс перестраивается мгновенно |
| Источник даты | Дата создания / изменения / обращения |
| Формат даты | 8 встроенных шаблонов либо свой код strftime |
| Включать время | Нет / Час-минута (1430) / Час-минута-секунда (14-30-05), с настраиваемым разделителем |
| Разделитель | Между датой и исходным именем: пробел, `_`, `-`, `.` или ничего |
| Позиция | Дата **перед** именем (префикс) или **после** него (суффикс, до расширения) |
| Выполнять сразу | Переименование сразу после щелчка; отключите, чтобы сначала открылось окно предпросмотра |
| Показывать окно результатов | После выполнения показывать окно с подробностями по каждому пункту (с отменой в один щелчок) |

### Дополнительные

| Параметр | Описание |
|---|---|
| Уже есть префикс даты | **Пропустить** (по умолчанию, чтобы не получилось `20151010 20151010 отчёт.pdf`) / Заменить старую дату / Добавить ещё одну |
| Конфликт имён | Автоматически добавлять `(1)`, `(2)`… либо пропускать |
| Область обработки | Файлы и папки / только файлы / только папки |
| Рекурсивно | При щелчке по папке обрабатывать всё её содержимое |
| Скрытые файлы | Обрабатывать ли скрытые/системные файлы (по умолчанию пропускаются) |
| Порядковый номер | Добавлять после даты `_001`, `_002`… (число знаков и разделитель настраиваются) |
| Исключить расширения | Например, `.lnk, .tmp` — такие файлы не обрабатываются |

### Язык интерфейса (новое в v1.1)

Список «Язык интерфейса» в верхней части окна настроек предлагает
**Русский / 简体中文 / English / 日本語**:

- весь интерфейс (вкладки, кнопки, подсказки, сообщения об ошибках, окна предпросмотра и
  результатов, а также примеры имён файлов в шаблонах формата даты) перестраивается мгновенно;
- выбор сразу записывается в файл конфигурации (`language`) и сохраняется между запусками;
- **текст пункта контекстного меню требует одного дополнительного щелчка** по
  «Зарегистрировать в контекстном меню», потому что он хранится в реестре, а не читается
  в реальном времени;
- при первом запуске язык определяется по системной локали (`LANG` / `locale`);
  если определить не удалось, используется 简体中文.

### Контекстное меню

- свой текст пункта меню (**оставьте поле пустым, чтобы следовать за языком интерфейса**);
- дополнительная регистрация на пустом месте внутри папки (действует на саму папку);
- после изменения текста или параметров требуется **повторная регистрация**; то же после
  перемещения программы.

### Отмена (усилено в v1.1)

- каждая партия автоматически записывается (хранятся последние 50 партий);
- восстановить партию целиком можно на вкладке «Отмена» или из окна результатов — имена
  возвращаются в обратном порядке;
- пункты, исходное имя которых уже занято, пропускаются с указанием причины;
- **«Очистить всю историю»** — удаляет все записи после подтверждения с указанием числа партий;
- **«Сохранять историю переименований (для отмены)»** — если снят флажок, история сразу
  перестаёт записываться (отмена становится недоступной); когда записей нет, кнопки
  автоматически блокируются, а под флажком показывается текущее состояние.

## 3. Частые форматы

| Желаемый результат | Настройка |
|---|---|
| `20151010 отчёт.pdf` | `%Y%m%d` + пробел |
| `2015-10-10 отчёт.pdf` | `%Y-%m-%d` |
| `2015_10_10 отчёт.pdf` | `%Y_%m_%d` + `_` |
| `20151010_1430 отчёт.pdf` | `%Y%m%d` + час-минута |
| `2015-10-10 14-30-05 отчёт.pdf` | `%Y-%m-%d` + час-минута-секунда |

Популярные коды strftime: `%Y` год (4 знака), `%y` год (2 знака), `%m` месяц, `%d` день,
`%H` час, `%M` минута, `%S` секунда, `%j` день года. Произвольный текст можно вводить как есть.

## 4. Командная строка

```bat
RenameTime.exe                  открыть окно настроек
RenameTime.exe --run ФАЙЛ...    выполнить по текущим настройкам (вызывается из меню)
RenameTime.exe --register       зарегистрировать контекстное меню
RenameTime.exe --unregister     убрать контекстное меню
RenameTime.exe --status         показать состояние регистрации
RenameTime.exe --undo           отменить последнюю партию
```

Перетаскивание файлов/папок на `RenameTime.exe` открывает окно предпросмотра.

## 5. Частые вопросы

**В: Язык переключился, но пункт меню остался старым.**
О: Текст пункта хранится в реестре и не обновляется в реальном времени. Откройте вкладку
«Контекстное меню» и нажмите «Зарегистрировать в контекстном меню» ещё раз.

**В: Можно ли зафиксировать текст пункта меню независимо от языка интерфейса?**
О: Да — впишите свой текст в поле «Текст пункта меню». Пустое поле означает «следовать за
языком интерфейса».

**В: Правый щелчок ничего не делает / пункта нет.**
О: Запустите exe → «Контекстное меню» → «Проверить состояние регистрации». Если программа
перемещена — зарегистрируйте заново. Каждый запуск записывается в
`%APPDATA%\RenameTime\launch.log`: там видно, что именно передала система и на каком шаге
остановилось.

**В: При выборе многих файлов будет много окон?**
Нет. Механизм проводника для обычных (статических) пунктов реестра устроен так, что
**на каждый выбранный файл запускается отдельный процесс**, а в командной строке можно
передать только `%1`. Программа объединяет эти процессы в **одну партию** по схеме
«очередь + ведущий процесс»: первый процесс становится ведущим, около секунды ждёт, пока
остальные передадут свои пути, выполняет всё разом, показывает одно окно результатов,
а прочие тихо завершаются. Побочный эффект — процесс запускается на каждый файл, поэтому
**при выборе нескольких десятков файлов потребуется несколько секунд** (exe распаковывается
и стартует), это нормально.

**В: Почему пункт меню самый верхний?**
Чтобы не путать со встроенным пунктом «Открыть» (по ошибке файл откроется в программе по
умолчанию — HTML-файл запустит браузер). Пункт закреплён вверху через `Position=Top`.

**В: Дата не накапливается при повторных щелчках?**
По умолчанию нет: если имя уже начинается с даты, файл пропускается. Чтобы заменить старую
дату новой, выберите «Заменять существующую дату» в дополнительных настройках.

**В: Что делать при ошибке?**
Нажмите «Отменить эту партию» в окне результатов или выберите партию на вкладке «Отмена».

**В: Файл занят / открыт в редакторе.**
Операция завершится ошибкой для этого пункта, причина будет указана в окне результатов;
на остальные файлы это не влияет.

**В: Очень длинные пути (более 260 символов).**
Программа внутренне использует API длинных путей `\\?\`, поэтому такие файлы обрабатываются.

Запуск из исходников (нужны Python 3.8+ и wxPython):

```bat
pip install wxPython
python rename_time.py            :: окно настроек
python rename_time.py --register :: регистрация контекстного меню (указывает на pythonw + скрипт)
```

Самостоятельная сборка exe (`pip install pyinstaller`):

```bat
python make_icon.py
python -m PyInstaller --onefile --windowed --name RenameTime --icon app_icon.ico rename_time.py
```

> Файл `i18n.py` подхватывается PyInstaller автоматически как зависимость.

Запуск всех тестов:

```bat
python test_i18n.py
python test_engine.py
python gui_smoke_test.py     :: требуется wxPython
python cli_smoke_test.py     :: требуется собранный exe
python shellexec_probe.py    :: требуется зарегистрированное контекстное меню
```

Настройки и история отмены хранятся в `%APPDATA%\RenameTime\`
(config.json / history.json / launch.log / rename_time.log).
